Switching parties means changing the party used to conduct transactions.

<Note>
These steps apply only if you are using the [Wallet Gateway](/integrations/wallet-gateway/overview) as your signing provider. Other CIP-103 wallets manage the primary party in their own interface.
</Note>

## Switch Your Primary Party

1. Navigate to the bottom of the side navigation and click the **Wallet Gateway** button.

   ![Wallet Gateway button at the bottom of the left navigation](/images/sdks-tools/splice-portfolio/wallet-gateway-button.png)

2. A pop-up window appears where you can review existing parties in the **Parties** tab. The selected party has a **Primary** tag to indicate which party you are currently operating from.

   ![Parties tab of the Wallet Gateway showing the primary party](/images/sdks-tools/splice-portfolio/wallet-gateway-parties.png)

3. Click **Set as primary** on another party to change it.

   You can also create a new party using the **+ New** button at the top. Check **Set as the primary party** if you want to use it right after creating it.

4. Go back to Splice Portfolio to continue conducting transactions with the new party.
