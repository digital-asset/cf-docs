## Disconnecting and Reconnecting to a Wallet Provider

If you are having trouble launching the Wallet Gateway or connecting to your wallet provider, disconnecting and reconnecting Splice Portfolio may help.

1. Click **Disconnect** in the left side navigation.

   ![Disconnect button in the left navigation](/images/dISCONNECTING-AND-RECONNECTING-TO-A-WALLET-PROVIDER-\(STEP-1\).png)

2. Once Splice Portfolio is disconnected from your wallet provider, you are redirected to the landing page.

   ![Splice Portfolio landing page after disconnecting](/images/sdks-tools/splice-portfolio/connect-wallet-landing.png)

3. Follow [First-Time Setup](/sdks-tools/development-tools/splice-portfolio/first-time-setup) to reconnect your wallet provider to Splice Portfolio.

If the issue persists after reconnecting, contact support.

## System Errors When Sending and Accepting Offers

If a system error occurs while sending or accepting an offer, an error message appears in the UI with the option to copy the logs. Review the logs to help troubleshoot the issue, or contact support for further assistance.

![System error message with a copy logs option](/images/sdks-tools/splice-portfolio/system-error-copy-logs.png)
